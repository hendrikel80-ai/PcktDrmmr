# Pocket Studio

Dein Schlagzeug zum Mitspielen: Beats aussuchen oder selbst bauen, Gitarre, Bass
oder Gesang dazu einspielen und alles zusammen als MP3 aufnehmen.

- **[Benutzerhandbuch](docs/Benutzerhandbuch.md):** Installation und Bedienung
  Schritt für Schritt
- **[User Guide (English)](docs/User-Guide.md):** installation and usage, step
  by step
- **[Download](https://github.com/hendrikel80-ai/PcktDrmmr/releases):** Windows-Installer
